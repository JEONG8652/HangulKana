# HangulKana

**한글 두벌식으로 일본어를 입력하는 Windows 상주 프로그램.**

한글로 소리 나는 대로 치면 로마자로 바꿔 Microsoft 일본어 IME에 보내 줍니다.
가나·한자 변환과 후보 창은 MS IME가 그대로 처리하므로, 변환 결과와 학습은 평소 일본어 입력과 같습니다.

| 입력 | 결과 |
| --- | --- |
| 가나 | がな |
| 쿄우 | きょう |
| 텐카잇핀 | てんかいっぴん |
| 츠 Shift+츠 키 | つづき |
| 와타시워미루 | わたしをみる |

## 특징

- 한국어 자판 그대로, 일본어 로마자 배열을 외울 필요 없음
- **Shift로 탁점**: 츠 → つ, Shift+츠 → づ
- **한글 띄움창**: 지금 치는 한글을 커서 위에 말풍선으로 보여 줌
- **초성 미리보기**: 자음만 쳐도 입력 위치에 ｋ처럼 표시
- 일본어 히라가나 모드일 때만 동작하고, 한국어·영문 입력에는 영향 없음
- 입력 내용을 저장하지 않으며 네트워크 통신을 하지 않음

## 요구 사항

- Windows 10 / 11
- 일본어 언어 팩과 **Microsoft IME**
  - 설정 → 시간 및 언어 → 언어 및 지역 → 언어 추가 → 일본어
- 일본어 IME의 하드웨어 키보드 레이아웃을 **영어(101키)** 로
  - 일본어 → 언어 옵션 → 하드웨어 키보드 레이아웃 변경. 106/109키로 두면 기호 위치가 한국 키보드 각인과 달라집니다.
- **로마자 입력** (かな入力 끔): 작업 표시줄의 あ 아이콘 오른쪽 클릭 → "かな入力" 해제

## 설치와 실행

1. `HangulKana.exe`를 원하는 폴더에 둡니다. 직접 빌드하려면 [개발](#개발) 참고.
2. 실행하면 작업 표시줄 오른쪽 아래(트레이)에 아이콘이 생깁니다.
3. 일본어 IME를 켜고 히라가나(あ) 모드에서 한글로 치면 됩니다.

| 트레이 아이콘 | 상태 |
| --- | --- |
| 🟢 초록 | 변환 중 |
| ⚪ 회색 | 대기 (한국어·영문 모드, Caps Lock, 관리자 권한 창 등) |
| 🟠 주황 | 일시 정지 |

**로그인 때 자동 실행**: `Win+R` → `shell:startup` → 열린 폴더에 `HangulKana.exe` 바로 가기를 넣습니다.

> **비상 정지**: 입력이 이상해지면 `Ctrl+Alt+Shift+Q`로 즉시 종료됩니다.
> 그래도 안 되면 `Ctrl+Alt+Del` → 작업 관리자에서 `HangulKana.exe`를 종료하세요.

## 입력 규칙

| 규칙 | 예 |
| --- | --- |
| 한 음절 = 가나 한 글자 (요음 포함) | 가 → が, 쿄 → きょ |
| 받침은 ㄴ·ㅇ → ん, ㅅ → っ 만 (나머지는 버림) | 간아 → がんあ, 겡키 → げんき, 갓타 → がった, 각 → が |
| `-` 키 → 장음 | 카레- → かれー |
| ㅇ 없이 친 모음 → 작은 가나 | ㅏ → ぁ, 테ㅔ → てぇ |
| 복모음 | 와 → わ, 화 → ふぁ, 위 → うぃ, 예 → いぇ |
| **워 → を** | 와타시워 → わたしを |
| 티·투·디·두 | てぃ·とぅ·でぃ·どぅ |
| ㅓ·ㅕ 등 일본어에 없는 모음 | 무시 |

### Shift = 탁점

음절의 자음이나 모음 중 하나를 Shift와 함께 치면 탁점이 붙습니다.

| 행 | 예 |
| --- | --- |
| 카·타·사·하·파 | Shift+카 → が, Shift+타 → だ, Shift+사 → ざ, Shift+하 → ば, Shift+파 → ば |
| 차·츠 | Shift+치 → ぢ, Shift+츠 → づ, Shift+챠 → ぢゃ |
| 우 | Shift+우 → ゔ |
| 아·이·에·오·야·유·요·와 | ゛를 따로 붙임: Shift+아 → あ゛ |
| 나·라·마, 가·다·바·자 | 그대로 |

- 예외: **Shift+ㅔ는 ㅖ** 입니다 (예 → いぇ). 케·테 등에 탁점을 붙일 때는 자음 쪽에서 Shift를 누르세요 (Shift+ㅋ, ㅔ → げ).

## 트레이 메뉴와 단축키

| 메뉴 / 키 | 기능 |
| --- | --- |
| 한글 띄움창 | 띄움창 켜기/끄기 (설정에 저장) |
| 일시 정지 · `Ctrl+Alt+P` | 변환을 잠시 멈춤 |
| 설정 파일 열기 | `config.toml` 열기 |
| 로그 폴더 열기 | 로그 폴더 열기 |
| 종료 | |
| `Ctrl+Alt+Shift+Q` | 비상 정지 (즉시 종료) |

## 설정

`%APPDATA%\HangulKana\config.toml` (처음 실행할 때 생성). 바꾼 뒤 다시 실행하면 적용됩니다.

```toml
overlay = true                 # 한글 띄움창
preview = true                 # 초성 미리보기 (ㅋ → ｋ)
pause_hotkey = "ctrl+alt+p"    # 일시 정지 단축키. ""이면 없음. 예: "ctrl+shift+f12"
log_level = "error"            # error / warning / info / debug
```

> `log_level = "debug"`는 입력한 내용이 로그에 기록되므로 문제를 조사할 때만 쓰세요.

## 알려진 제한

- **관리자 권한 창**(관리자 명령 프롬프트 등)에서는 동작하지 않습니다. Windows 보안 정책상 일반 프로그램이 관리자 창에 키를 보낼 수 없어, 자동으로 대기 상태가 됩니다.
- **Caps Lock이 켜져 있으면** 변환하지 않습니다.
- 자음을 친 직후 클릭·창 전환·단축키를 누르면 미리보기 글자(ｋ 등)가 남을 수 있습니다. 백스페이스로 지우면 됩니다.
- 일부 앱(Chrome, VS Code 등)은 커서 위치를 알려 주지 않아 띄움창이 화면 오른쪽 아래에 뜹니다.
- 키보드 입력을 가로채는 방식이라 백신이 경고할 수 있습니다.

## 삭제

1. 트레이 메뉴 → 종료
2. `shell:startup` 폴더에 넣은 바로 가기 삭제
3. `HangulKana.exe`와 `%APPDATA%\HangulKana` 폴더 삭제

레지스트리나 시스템 설정은 바꾸지 않습니다.

## 개발

Python 3.10 이상.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt

.venv\Scripts\python.exe -X utf8 -m pytest                                 # 단위 테스트
.venv\Scripts\python.exe -X utf8 -m hangulkana                             # dry-run (키를 가로채지 않음), 60초 후 종료
.venv\Scripts\python.exe -X utf8 -m hangulkana --live --max-seconds 300    # 실제 변환, 5분 후 종료
.venv\Scripts\python.exe -X utf8 tools\build_exe.py                        # dist\HangulKana.exe 빌드
```

소스로 실행하면 설정·로그는 프로젝트의 `.devdata\`에 생깁니다.

| 모듈 | 역할 |
| --- | --- |
| `layout.py` | 키 코드 → 두벌식 자모 |
| `romaji_table.py` | 음절 → 로마자·가나 표, 탁점 |
| `engine.py` | 자모 입력 → 송신할 키, 조합 추적, 띄움창 표시 문자열 |
| `config.py` | 설정 파일, 단축키 해석 |
| `hook.py` | 저수준 키보드·마우스 훅, SendInput |
| `ime_state.py` | 포커스 창의 언어·IME 모드 감시 |
| `app.py` | 트레이, 띄움창, 수명 주기 |

`layout`·`romaji_table`·`engine`·`config`는 Windows API를 쓰지 않아 어디서나 단위 테스트할 수 있습니다.
